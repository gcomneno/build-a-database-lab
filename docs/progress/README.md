# Progress tracking

Questo documento separa la preparazione del repository dall'attività reale del
learner, dall'implementazione e dalla verifica.

## Repository preparation

Stato corrente: Prepared

Stati ammessi:

- Preparation in progress
- Prepared

## Learner activity

Stato corrente: not studied

Stati ammessi:

- not studied
- studying
- studied

## Implementation

Stato corrente: not started

Stati ammessi:

- not started
- partial
- implemented

## Verification

Stato corrente: not applicable

Stati ammessi:

- not applicable
- not run
- partial
- verified

`not applicable` è lo stato iniziale perché non esiste ancora alcuna
implementazione da verificare.

## Stato canonico corrente

| Asse | Stato |
|---|---|
| Repository preparation | Prepared |
| Learner activity | not studied |
| Implementation | not started |
| Verification | not applicable |

La preparazione dell'ambiente non costituisce attività di studio.

La presenza futura di codice non costituirà prova di verifica.

Una Lesson Learned potrà essere registrata solo dopo lavoro realmente svolto.

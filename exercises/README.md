# Exercises

Questa directory conterrà esercizi originali collegati al percorso didattico.

Stato corrente: no exercises

## Regole

Distinguere sempre tra:

- esercizio preparato;
- esercizio tentato;
- esercizio completato;
- esercizio verificato o revisionato.

Preparare un esercizio non significa averlo svolto.

Gli esercizi non devono diventare copie meccaniche delle attività presenti nelle
fonti esterne.

# Lesson Learned

Questa directory conterrà Lesson Learned riutilizzabili prodotte dopo sessioni
di lavoro realmente svolte.

Stato corrente: none

## Requisito di evidenza

Una Lesson Learned deve derivare da almeno una reale attività pertinente, per
esempio:

- studio;
- esercizio;
- implementazione;
- verifica;
- debugging;
- confronto architetturale.

Non devono essere create Lesson Learned preventive, speculative o basate sulla
sola preparazione del repository.

Ogni Lesson Learned futura dovrebbe rendere distinguibili:

- contesto;
- attività realmente svolta;
- evidenza osservata;
- comprensione acquisita;
- errori o limiti emersi;
- takeaway riutilizzabili;
- fonti pertinenti.

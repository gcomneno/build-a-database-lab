# Theory

Questa directory conterrà note teoriche e spiegazioni originali prodotte durante
lo studio reale.

Stato corrente: not studied

## Regole

Il materiale inserito qui deve:

- derivare da attività di studio realmente svolta;
- distinguere osservazioni delle fonti da interpretazioni originali;
- attribuire le fonti quando necessario;
- evitare copie sostanziali del materiale sorgente;
- non essere presentato come Lesson Learned prima della relativa consolidazione.

La sola presenza di questa directory non costituisce prova di studio.

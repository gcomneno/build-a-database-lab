# Implementations

Questa directory conterrà implementazioni prodotte realmente nel laboratorio.

Stato corrente: not started

## Regole

Prima di introdurre codice devono essere motivate almeno:

- la finalità didattica dell'implementazione;
- la tecnologia scelta;
- il rapporto con le fonti utilizzate;
- il comportamento atteso;
- il metodo di verifica previsto.

La tecnologia usata da una fonte esterna non viene adottata automaticamente.

La presenza di codice implica soltanto attività di implementazione realmente
svolta e non costituisce prova di verifica.
